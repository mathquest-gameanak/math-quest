# Naskah Suara (voiceover) Math Quest

Rekam setiap baris sebagai file **MP3** bernama sesuai kolom *File*, simpan di folder `audio/vo/`, lalu kirim daftar file-nya ke Claude agar didaftarkan di `MQ.Story.VO` (js/story.js).

- Baris dengan **(nama pahlawan)**: rekam tanpa menyebut nama, mis. "Halo, Pahlawan!" — teks di layar tetap memakai nama anak.
- Saran: suara ceria & pelan, 1–2 detik jeda di akhir. Naskah dibuat otomatis dari js/story.js; jangan diedit manual.

Pratinjau per area

MusuhHPPukulDmg/KOJedaSerangXP

Pukul = jawaban benar untuk mengalahkan musuh. Dmg/KO = damage musuh ke pemain / berapa pukulan musuh sampai pemain pingsan. Jeda = rata-rata detik antar serangan musuh. Serang = berapa kali musuh sempat menyerang sebelum kalah (merah = 0, musuh tidak sempat menyerang).
